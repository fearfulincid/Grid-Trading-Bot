## FAQ

<details><summary>When is grid trading most profitable?</summary>
Grid trading works best in ranging/sideways markets where price oscillates between support and resistance levels.
</details>

<details><summary>What happens if price moves outside the grid?</summary>
If price goes above the grid, all positions are sold. If below, all grid positions are filled. Use trailing grids for trends.
</details>

<details><summary>How many grids should I use?</summary>
More grids mean smaller profit per trade but more frequent trades. 10-50 grids is typical depending on the price range.
</details>

<details><summary>Can I run grids on multiple pairs?</summary>
Yes, create separate grid strategies for different pairs with independent parameters and budgets.
</details>
